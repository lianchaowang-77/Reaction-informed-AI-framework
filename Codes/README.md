# Code Release

This directory contains the code used in the AI-driven design of degradable marine antifouling materials.

## Sections

1. **ML models**: eight RD-driven models for hydrolysis-rate prediction and eight surrogate models for DFT-derived properties.
2. **Targeted search**: five guided algorithms for discovering molecules that exceed the current hydrolysis-rate limit.
3. **Inverse design**: five algorithms for designing molecules with a specified hydrolysis rate.



See the README in each section for its contents and basic usage.
