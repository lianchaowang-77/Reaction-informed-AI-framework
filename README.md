# Reaction-Informed AI Design of Acid-Responsive Hydrolyzable Molecules for Marine Antifouling

This repository contains the code and supplementary data developed for the AI-driven design of degradable marine antifouling materials. The project integrates reaction-informed machine learning, molecular screening, targeted search, and inverse design to predict hydrolysis rates and identify acid-responsive hydrolyzable molecules.

## Repository Structure

- **`Codes/`** contains the machine-learning models for hydrolysis-rate prediction, five targeted-search algorithms, and five inverse-design algorithms.
- **`Supplementary_Data/`** contains the experimental dataset, reaction-descriptor matrices, surrogate-model training data, virtual screening results, substituent records, and designed molecular candidates.

See the README files in the corresponding directories for data descriptions and instructions for running the code.
